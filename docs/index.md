## Overview

This project provides:

- Kafka producer/consumer utilities
- Protobuf schema generation from Java POJOs
- Configuration loader for `application.properties`

### Packages

- `org.example` — entry point
- `org.example.kafka.builder` — `KafkaProducerBuilder`, `KafkaConsumerBuilder`
- `org.example.kafka.service` — `KafkaService`
- `org.example.config` — `PropertiesLoader`
- `org.example.resolver` — `ProtobufUtils`, `ProtoSchemaGenerator`
- `org.example.model` — `User` POJO

Refer to the package pages under `packages/` for full API references and examples.
